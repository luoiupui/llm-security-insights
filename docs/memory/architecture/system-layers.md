The system follows a formal four-layer architecture:
1. Data Acquisition: Multi-source ingestion.
2. LLM Extraction: NER and relation mapping.
3. Knowledge Graph Storage: Temporal KG with conflict detection.
4. Inference Application: Neuro-symbolic reasoning engine.
